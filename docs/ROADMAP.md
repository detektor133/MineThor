## Известные проблемы базы (чинить в Фазе 0)
1. Чтение состояния с сокет-потока, не с client thread → гонки, «мигание» disconnected.
2. Фиксированный порт `25566`, нет токена → любое приложение на устройстве может подключиться.
3. Иконки: `removeEdgeBlackBackground` — костыль flood-fill вместо настоящего альфа-канала; качество и размеры нестабильны.
4. Маппинги только Mojang → Fabric/Quilt/старый Forge не покрыты (см. COMPATIBILITY).
5. Иконки не работают до 1.20 (`GuiGraphics`).
6. Нет capability report и unit-тестов протокола.

## Фаза 0 — Фундамент (блокирует всё)
- [ ] Выполнение всех чтений/команд на client thread; сокет-поток только ставит в очередь и читает готовый snapshot
- [ ] Одноразовый токен на запуск (лаунчер генерирует → аргумент агенту → handshake); порт выбирается свободный и передаётся
- [ ] Protocol v4: `requestId` у команд, `ACK`/`REJECTED_*`, heartbeat, лимит размера, `capabilities` в HELLO
- [ ] Snapshot по изменению (diff / dirty flag), а не безусловно каждые 100 мс
- [ ] Unit tests: codec, stale state, unknown protocol version
- [ ] Вынести резолвер маппингов/descriptor в чистый Java-модуль без Android API (нужен для conformance-тестов на JVM, см. [TESTING.md](TESTING.md))
- [ ] Скрипты `scripts/minethor/` (smoke, замеры) и каркас CI
- [ ] Лаунчер: чёткие статусы подключения (нет агента / нет маппингов / версия протокола / ок) — строки в resources

**Приёмка:** 30 минут игры без «мигания» HUD; чужое приложение без токена не может подключиться; тесты зелёные.

## Фаза 2 — Нормальные иконки (пункт 4)
См. [UI_GUIDE.md](UI_GUIDE.md#иконки). Гипотеза «проблема в чёрном фоне и flood-fill» не проверена — поэтому сначала **bake-off нескольких вариантов**, потом выбор.

Варианты (сменные `IconProvider`):
- **A. FBO из игры:** offscreen FBO с прозрачным clear, фикс. размер 64 и 128 px (текущий путь, но без flood-fill/trim).
- **B. Android-рендер из ассетов:** парсинг model JSON + текстуры (учёт ресурспака), плоские предметы — спрайт напрямую, блоки — изометрическая проекция.
- **C. Гибрид:** плоские предметы по B (пиксель-перфект, nearest neighbor), блоки/сложные/модовые по A.
- **D. Текущая реализация** — контрольная группа.

Протокол сравнения: 20 предметов (блок, инструмент, зелье, голова, щит, зачарованный, окрашенная броня, модовый, анимированные часы/компас) × версии (минимум 1.12.2, 1.16.5, 1.20.1, 1.21.x, 26.x) → скриншоты на Thor рядом с ванильным GUI. Метрики: SSIM к эталону + экспертная оценка, охват версий/модов, время получения, память/диск, батарея, сложность поддержки.
- [ ] Провайдеры A/B/C, общий интерфейс, переключатель в debug
- [ ] Эталонные скриншоты и отчёт в `docs/perf/icons/`
- [ ] Выбор по итогам; остальные удалить или оставить как fallback
- [ ] Общее: настоящая альфа, единый размер, count/durability рисует Android, дисковый кэш (версия × ресурспак × item), LRU в памяти, батч-запросы, приоритет видимых слотов

**Приёмка:** на Thor иконки визуально совпадают с ванильными, без чёрных ореолов, одинаковый масштаб; решение подтверждено сравнением.
